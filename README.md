## ✨ Overview
This repository contains a small Python application that:
- generates large prime candidates,
- checks primality with basic tests (trial division / variants),
- saves example inputs/outputs for quick verification.

> The code is for **educational** purposes (not production-grade cryptography).

## 🧩 Features
- Prime candidate generation and primality checks
- Simple CLI run via `main.py`
- Sample data files for quick testing
- Clear folder layout and ignore rules for secrets/logs
